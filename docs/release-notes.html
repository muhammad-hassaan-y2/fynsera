Release Notes

This page tracks major updates to the Fynsera platform and this documentation. Update this file as the product evolves — each entry should note what changed and why it matters to someone running a live rollout.

v1.0 — Initial Release​

  • Core Nervous System and Governance Layer (Workforce OS) launched
  • Office agent roster available: Project Intelligence, Field Voice, Scheduling, Procurement, Cost Intelligence, Contract & Compliance
  • Autonomy Level framework (L1–L4) and hard-exit rules established
  • 60-day pilot program structure defined
  • Full documentation published: Getting Started, Core Concepts, Agent Roster (Office), Governance & Control, Security & Data, Implementation & Rollout, Pricing & Plans, FAQs & Objections, Glossary

Planned — Phase 2​

  • Yard & plant agent roster: Prefab & Modular Fabrication, BIM-to-Fabrication, Quality Inspection, Inventory & Yard, Equipment & Fleet, Punch List & Closeout
  • Documentation expansion covering Phase 2 rollout timelines and integration requirements
