# Glossary

**Audit Log** — The complete, unified record of every action any agent has taken: what triggered it, what data was read, what was decided, what action resulted, and who approved it.

**Autonomy Level (L1–L4)** — The scale describing how independently an agent may act on a given task, from full human review (L1) to independent operation within approved scope (L4). See [Core Concepts](./03-core-concepts.md#autonomy-levels-explained).

**Digital FTE** — An AI agent treated as a roster member rather than a script: hired for a defined task, assigned work, governed by rules, observed through logging, and retired when no longer needed.

**Governance Layer** — See *Workforce OS*.

**Hard Exit** — A standing condition — legal exposure, cost above a threshold, safety flags, conflicting data, and similar — that always routes a decision to a human, regardless of an agent's earned autonomy level.

**Heartbeat** — The loop by which an agent wakes on a schedule or a live event, checks the System of Record, decides, and acts, without needing a person to trigger it.

**Nervous System** — Fynsera's real-time sensing layer: the combination of heartbeats, live data ingestion, and the System of Record that lets agents act on current information rather than stale reports.

**Phase 2** — The yard and plant portion of the agent roster (prefab, BIM-to-fabrication, quality inspection, inventory, equipment, punch list/closeout), typically rolled out after the office roster is stable.

**Pilot** — The initial 60-day engagement on a single live project, used to prove ROI before any larger commitment. See [Pricing & Plans](./09-pricing-plans.md#the-60-day-pilot-program).

**System of Record** — The single, trusted source of current, correct project data that every person and every agent reads from and writes to, connecting existing tools (scheduling, accounting, documents) rather than replacing them.

**Verifier** — The automated check used at Autonomy Level L2, which reviews an agent's output and flags only the uncertain cases for human review, rather than requiring full manual review of everything.

**Workforce OS (Governance Layer)** — The layer sitting between every agent and your business systems, responsible for five functions: Hire, Assign, Govern, Observe, and Retire. See [Core Concepts](./03-core-concepts.md#the-governance-layer-workforce-os).
